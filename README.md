# Arbuzik VPN Bot 🍉

Telegram-бот для продажи VPN — **всё в одном файле `bot.py`** (aiogram 3),
подключён к панели H1 VLESS (`germany-d1.h1cloud.net`).

## Файлы

| Файл | Что это |
|---|---|
| `bot.py` | Весь бот: настройки, панель, CryptoBot, база, туннель, веб-сервер |
| `miniapp.html` | Мини-приложение Telegram (HTML, можно править дизайн) |
| `bot.db` | База пользователей и оплат (создаётся сама) |
| `install.bat` / `start.bat` | Установка (один раз) и запуск |

## Возможности

**Для пользователей:**
- 📋 **Моя подписка** — статус, дни, трафик, устройства + ссылки и QR
- 🎁 **Бесплатная** — пробная подписка 3 дня (один раз на аккаунт)
- 🔑 **Мой ключ** — vless-ключ, ссылка подписки (Happ/v2tunes/Hiddify) и для Incy
- 💳 **Купить подписку** — тарифы 85 / 340 / 500 ₽
  - 🪙 **CryptoBot** — счёт в рублях, оплата криптой, активация автоматически ~1 мин
  - 💳 **Картой** — перевод, подтверждает админ
- 🍉 **Мини-приложение** — веб-приложение внутри Telegram (статус, покупка, ссылки)
- 📱 **Приложения** — инструкции Happ / Incy / v2tunes
- 💬 **Поддержка** — сообщение админу, ответ через /reply
- ⏰ Автонапоминания за 3 дня до конца подписки и при истечении

**Для админа:**
- `/stats` — пользователи, активные/истёкшие подписки, выручка (крипта/карта, всего и за 30 дней)
- `/user <id>` · `/give <id> <дней>` · `/paid <id> <сумма> [дней]`
- `/send <текст>` — рассылка · `/reply <id> <текст>` — ответ в поддержку
- Заявки на оплату картой приходят с кнопками ✅ Подтвердить / ❌ Отклонить

## Мини-приложение

`bot.py` при старте поднимает локальный веб-сервер (порт 8080 из настроек
в начале файла) и HTTPS-туннель через бесплатные сервисы (pinggy.io →
localhost.run, без регистрации). Когда туннель поднимется, в боте
автоматически появится кнопка меню «🍉 Арбузик» и кнопки «Открыть приложение».

Внешний вид и тексты мини-приложения правятся в `miniapp.html` — файл
перечитывается при каждом открытии, перезапускать бота не нужно.

## Настройка (начало bot.py)

| Что | Переменная |
|---|---|
| Реквизиты оплаты картой | `PAYMENT_INFO` |
| Тарифы (название, дней, устройств, ₽) | `TARIFFS` |
| Пробная подписка | `TRIAL_DAYS`, `TRIAL_GB`, `TRIAL_DEVICES` |
| Крипто-платежи | `CRYPTOBOT_TOKEN` |
| Токен бота / админ | `BOT_TOKEN`, `ADMIN_ID` |

## Важно

- Не показывайте никому начало `bot.py` — там токены бота, панели и CryptoBot.
- Бот должен быть запущен, чтобы работал: держите `start.bat` открытым
  (или настройте автозапуск Windows).
- В панели H1 НЕ включайте встроенного «Бот-магазина» (раздел «Бот») —
  тот же токен, конфликтуют (его токен уже очищен).
- Если поменяется IP сервера — обновите `SUB_BASE` в начале `bot.py`.
